# v0.8.0 遷移與版本選擇

本輪選擇 **0.8.0（minor）**：新增協商式 applied 回執、對外 diagnostics 欄位、SemanticState
consumer 契約與持久化恢復能力，超過單純修補。已發布 peer 可繼續互動，既有 AIP 欄位與合法語意不改，
不需要 major。錯型別、非法日期、explicit null 等修正回到既有契約，不新增容忍開關。

| 版本軸 | 本輪 | 遷移／相容 |
|---|---|---|
| 產品 | 0.7.0 → 0.8.0 | 四份 manifest＋lockfiles 由 release-prepare 處理 |
| AIP | aip/1.0 | 保留既有接收決策與未知選填欄位；沒有循環 crate 依賴 |
| Device wire | proto 1、既有 v1.x framing | 新 `aip.applied/1` profile 只對協商者使用；舊 peer 不被要求新訊息 |
| SemanticState profile/schema | semantic-state/1.0 | 新增獨立生成契約；wire JSON、validated state、renderer projection 分離 |
| Session snapshot | format 1 | 既有 format 0／缺 unsupportedIntents 遷移保留；future parked 原檔不動 |
| Sensor journal | 新 format 1 SQLite meta | 首次建立；raw capture 開始即 write-ahead，同 scope 停止才確認；舊 memory-only unknown 無法補造 |
| Desktop preset marker | 舊 format 0 → 新 format 1 | 無 Runtime revision 的舊 marker 不覆寫不同有效值；future/malformed raw marker 保留 |
| Desktop／Runtime config revision | 各自新增、缺省 0 | 十進位字串、不同 owner；不是 AIP revision，不帶到偏好備份 |
| 設定備份 | schemaVersion 1 | missing optional 保留；present wrong type 拒絕；空名字確實清除；未知角色先安裝 package 再匯入 |

升級前可沿用設定匯出與資料目錄備份。不要刪除 journal、快照或授權資料來通過啟動；壞／future
資料的可見狀態屬正常保護。高風險 enabled 與 consent 按原安全規則重新計算，備份不替人授權。
Unix 新偏好檔／原子替換檔只保留 owner 讀写位元（最多 0600），不恢復群組／其他使用者可讀位元。

回退請保留完整 desktop.json 與 SQLite／Session 備份。v0.7.0 不理解新 journal 與 revision：回退會失去
本輪跨重啟 unknown 顯示與競態保護；新回執未協商時只剩傳送證據，不能顯示「已驗證效果」。
