## 4. 協定／儲存遷移

- **hash 契約不變**（AIP 1.0 canonical 未改、無 wire 版本變更）：明定數字字面＝serde_json（f64 整數值 `x.0`，`-0.0` host 永不產生），
  iOS 逐字保留、TS 依 `stateHashDoublePaths` 重印；三端 `stateHashes` fixtures 9 份。
- **快照容器格式版本** `Snapshot.format`（0＝v0.6.0 無版本、1＝現行；不進 hash、不上 wire）：五種載入結果、備份 `character-session.json.pre-format-<n>`、
  downgrade 矩陣（v0.6.0 讀 format 1 可；未來 state 新欄位 v0.6.0 讀會隔離）。
- **持久化順序**：`SessionStore::save → SaveOutcome`，(epoch, revision) 同鎖 guard；不宣稱網路 exactly-once。
