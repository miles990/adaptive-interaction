## 4. 協定／儲存遷移

- **hash 契約不變**（AIP 1.0 canonical 未改、無 wire 版本變更）：明定數字字面＝serde_json（f64 整數值 `x.0`，`-0.0` host 永不產生），
  iOS 逐字保留、TS 依 `stateHashDoublePaths` 重印；三端 `stateHashes` fixtures 9 份。
- **快照容器格式版本** `Snapshot.format`（0＝v0.6.0 無版本、1＝現行；不進 hash、不上 wire）：五種載入結果、備份 `character-session.json.pre-format-<n>`、
  downgrade 矩陣（v0.6.0 讀 format 1 可；未來 state 新欄位 v0.6.0 讀會隔離）。
- **持久化順序**：`SessionStore::save → SaveOutcome`，(epoch, revision) 同鎖 guard；不宣稱網路 exactly-once。

## 11. 剩餘限制與下一版本建議

剩餘限制（全部已記在 CHANGELOG `[Unreleased]` Known limitations 或各文件）：

- **真機／真板零執行**：iPhone AIP 層（含 lifecycle／heartbeat／resume 防重入）只有 iPhone 17 模擬器；ESP32 只有 pty 模擬器＋`compile.sh`。
- **Serial 成員拿不到 snapshot 與含 members 的 patch**（1019／660–784 bytes > 639 bytes 單行）；分段或 per-member diff 屬協定層決定。
- **三端對「snapshot epoch 不同但非 session-reset」不一致**（TS realign 較嚴；Rust／Swift 接受）；`MAX_RESUME_PATCHES` 為桌面自訂上界。
- **宣告式裝置 Disabled→Available 需重啟才重新綁定**（誠實標注 `needs-restart-to-rebind`）；純 HTTP 宣告式來源的高風險受器停止後持續 stop-unknown。
- **行為變更**：另一支 iPhone 仍在操作中時，通用停用／撤銷一台不再關 `iphone.*` 全域旗標（全關請用停止所有感測／緊急停止）。
- iOS 背景閘門的 ConnectionManager 接線無自動化測試；10 s resume 寬限窗非跨端契約；`@unknown default` 只能 by-construction 覆蓋。
- 桌面：`CharacterPreview.tsx`／`CharacterLibrary.tsx` 頁面層棘輪未收斂；同步卡指名手機的捲動只在 jsdom 驗證；parked store 需重啟恢復；
  陪伴預設兩段寫入仍非原子（已有 busy＋世代守衛，但不是交易）。
- 測試機具：`serial.rs::a_port_that_dies_immediately_backs_off_and_is_reported_offline` 既有偶發；pty 模擬器啟動期限已放寬到 20 s。
- 非開發者測試腳本尚未有受測者；Tauri-only 正向路徑（換角色、陪伴檔位、勿擾、顯示／隱藏）未在真 Tauri 視窗走查。
- 證據截圖 87 張（12 MB）進 repo；v05-evidence 保留為歷史。
