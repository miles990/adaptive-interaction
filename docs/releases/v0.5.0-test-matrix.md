### Phase 9 第二輪最終效能量測（`pnpm perf`，2026-09-03，headless Chromium、Apple M2 Pro；非 Tauri WKWebView）

> 第二輪對抗審查修復（`perf-claims-007/008/009`）後的最終一次跑；microbenchmark（合成事件驅動的
> headless Chromium 迴圈），不是 Tauri WKWebView 實機數字。

| 指標 | 結果 |
|---|---|
| drawRig 單角色一幀 | median **0.100 ms** / p95 0.130 / max 1.270（n=72） |
| 舞台一幀（stage frame） | median **0.220 ms** / p95 0.500 / max 0.520（n=120） |
| rAF 間隔 | median **8.3 ms** / p95 9.0 / max 9.4（n=600） |
| 抓玩具延遲（toy grab） | median **8.4 ms** / p95 9.3（n=20；WebView-only segment，不含主機端點擊穿透閘） |
| 看向游標延遲（gaze） | median **8.3 ms** / p95 8.5 |
| JS heap（600 幀前／後／GC 後） | 3.02 → 3.93 → 2.26 MB（after GC） |
| heap 浸泡（60 s） | after-GC **1.92 → 2.14 MB（Δ +223 KB）** |
| **heap 浸泡（10 分鐘，`PERF_SOAK_MS=600000`）** | **600.0 s／72,008 幀／299 次抓玩具，after-GC 1.92 → 2.12 MB（Δ +210 KB，10.7%），GC 前峰值 8.37 MB** |

10 分鐘浸泡的 GC 後增量（+210 KB）沒有比 60 秒浸泡（+223 KB）大，判讀為固定保留集合而非隨時間累積的
洩漏；**30 分鐘浸泡未執行**。`perf-claims-009` 的修復把 soak 量測範圍擴大到涵蓋
`CharacterGateway`（真 shu adapter）／`InteractionDirector`／behavior／記憶／500 筆事件環（原本只有
`StageRenderer`），因此本輪數字與 Phase 8 的 60 s 數字（+231 KB，`StageRenderer` only）量測範圍不同，
不是直接可比的回歸；`perf-claims-007` 加上 Reduced Motion 靜態短路（實測 361 tick 只畫 7 幀）；
`perf-claims-008` 加上以顯示器自身節奏為基準線的 pacing 降級判斷（30 fps 降級不再只靠 JS 成本超支觸發）。
