## 2. 同環境基線與本輪描述性比較

基線是已下載核對的 v0.7.0 Release `.app`（source `630b4291f6a59444cfb1d8185f757f9dcda9ecc4`）；candidate是本輪固定source `3b375bde4188e4a039852881d48d82ea9b619ce1` 的release build（產品來源最後變更`87b0d031`）。兩者同一macOS/WKWebView、AX helper、fixture與操作定義。baseline driver內容hash對應`87b0d031`；candidate `3b375bd`僅加嚴最後結果gate，沒有改操作、等待或計時。

這是每組一次的腳本描述，不是使用者成功率改善或效能回歸結論。所有必需任務包含人工解除時仍有1項not-run；9/9只指自動工程子集。主要決策、回頭、求助與真人耗時未量；腳本沒有求助不代表人不需要幫助。手機/備份/取消是本輪追加驗收，沒有相同舊版完整基線，不報改善百分比。各step的時長與成功click保存在原JSON。settings/mobile/work 的 `elapsedSeconds` 是從該runner開始累計，差分才是單步耗時；wrapper seconds另含setup/cleanup。

## 3. 可及性與390px

完整 Playwright Chromium 92/92，`87b0d031`，222.34s。包含鍵盤Tab/Shift+Tab、解除對話框初始container不漏焦點、Escape focus返回、對話框仍可到緊急停止、Reduced Motion與展開細節往返；空dialog由component單元另驗，沒有冒充Browser實跑。ARIA/AX語意可讀不是VoiceOver真人驗收。task outcomes保存腳本決策/click/backtrack/耗時，不換算真人量測。
