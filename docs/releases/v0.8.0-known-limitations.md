# v0.8.0 剩餘範圍與環境需求

這是候選版本的限制清單；實跑狀態以 [progress](next-convergence-progress.md) 與
[evidence index](evidence-index.json) 為準，沒有把「已揭露」寫成「已修復」。

| 範圍 | 狀態／影響 | 依據與下一動作 |
|---|---|---|
| 真 iPhone AIP／applied | needs-environment；本輪無真機執行 | iOS XCTest 與 fake_iphone 是模擬器；取得真機後驗 TLS、URLSession、背景／重連與原子套用回執 |
| ESP32 真板／分片／applied | needs-environment；參考板仍有限能力 | 韌體只有 default/BLE compile；639-byte Serial、480-byte host BLE 上限不變；參考韌體不宣告未實作能力 |
| MQTT／BLE applied 專屬閉環 | not-run；共用 tracker 不等於各 transport 已驗 | MQTT 既有 broker rebind 是模擬器；補各自 applied／cancel／舊 generation 迴路 |
| 真人可用性與解除 emergency stop | needs-environment/not-run | AX script seconds／點擊不是人類耗時；不代人解除 latch。沿用非開發者腳本招募受測者 |
| macOS native UI 不在 CI | accepted limitation | 需桌面 session／既有 AX 權限；使用已提交 native scripts＋binary digest 重跑 |
| 同步證據 | accepted limitation | applied 是 peer 自報，非已看見螢幕或實體效果；legacy peer 沒回執時不判目前同步 |
| iOS socket／heartbeat | accepted limitation | URLSession 真回呼執行緒與裝置排程未實測；沿用 status 心跳，沒有新 AIP heartbeat |
| 兩個設定 store | accepted limitation | 可恢復、可讀回、可保留較新選擇；不是跨程序 ACID。native故障proxy、真檔案、component回應遺失各自分列 |
| Sensor journal 舊資料／容量 | accepted limitation | 無法補造 v0.7.0 memory-only unknown；overflow／store failure 保守提醒，不以 TTL 或同 ID 新連線解除 |
| 真實停止證據 | accepted limitation | scope 只代表目前可信連線，沒有通用 hardware incarnation；手機自報 false 不提升到物理驗證 |
| Removed port、RendererPort／DevicePort | experimental | 沒 production consumer 的 extension 不稱穩定 SDK；移除角色包走既有 host application store |
| 角色頁面棘輪、其餘偏好寫入入口 | 沿承 | 本輪收斂 preset／import，沒有全面重寫 UI 與 close behavior；既有架構守門保留 |
| 效能範圍 | 限定測量 | headless Chromium rig/stage；非 WKWebView／OS／validator／網路端到端。三次樣本不足統計推論，60s不足排除長期leak |
| 安裝平台 | 沿承 | 未簽章、未公證、無 SBOM/provenance；可用 macOS arm64 實際 smoke，其他平台只報 CI/資產檢查與 not-run 安裝 |
| 首輪本機發布驗證非0 | not-reproduced；原因未知，未宣稱fixed | main1fa69b8首次workspace失敗，原腳本丟掉細項輸出；同SHA捕獲診斷1278/0與完整發布驗證0skip成功。保留第一輪結果；再發生時用保存stdout/stderr的wrapper取得具體用例，不靠重跑隱藏失敗 |

本輪有明確改動的舊限制：v0.7.0 §2.3 merged-state fixture、§2.13 applied 缺口（限協商者）、§3.2
安全 rebind 預設的測試、§3.4 unknown 持久化、§4.1 真 preset recovery、§4.5 UUID、§6.1 schema、
§6.4/6.5 可執行 drill/Swift。§6.2 null 序列化防線本來就存在，本輪修正文案並另修 raw restore。
其餘 [v0.7.0 限制](v0.7.0-known-limitations.md) 中未被上述需求或本輪 report 明確替代的 by-design／
deferred 邊界仍保留（SSE世代標記、scope-only projection、patch hash相容、無自動分片重送、舊版遷移等）。
真機／真人限制沿用既有發布政策；所有本輪新增的必要工程檢查仍須通過才可 tag。
