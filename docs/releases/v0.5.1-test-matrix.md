## 3. 真 Tauri 視窗驗收（2026-09-04）

> 這一節是本輪新增的證據等級：不是 jsdom、不是 Chromium、不是 mock IPC，而是實際跑起來的
> `.app` 視窗。**逐項照抄驗收當下的紀錄，未驗的列明寫未驗。**

**組態**

- App：`pnpm tauri build --debug --bundles app` 產出的 `interaction-control-center.app`（debug 組態；
  前端 dist 為分支在 commit `8ba2a51` 時的內容；Rust host 含 `companion_hit_regions`），以隔離 home
  （`INTERACT_AI_HOME` 指向暫存目錄）啟動，內嵌 Runtime 綁 `127.0.0.1:8787`。
- Agent 二進位以 `INTERACT_AI_CLAUDE_BIN`／`INTERACT_AI_CODEX_BIN` 指向
  `tests/fixtures/fake_claude.sh`／`fake_codex.sh`（**fixture，非真 Claude Code／Codex**）；
  `INTERACT_AI_MOBILE_ADVERTISE=0`（行動伺服器只綁 127.0.0.1，`lsof` 確認，不對區網廣播）。
- 驅動方式：macOS System Events（AX 樹遞迴走訪點按鈕／讀文字）＋ Core Graphics 真滑鼠事件
  （`CGEventPost`，用來測點擊穿透；AX 的 `click at` 會繞過 ignore-cursor-events，不能拿來測穿透）
  ＋ `screencapture -R` 區域截圖（只截自己的視窗區域；含到使用者其他視窗的截圖已刪除，不入 repo）。
