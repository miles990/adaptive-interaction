## 2. 任務量測

### 2.1 本輪實跑（自動化，`taskMetrics.ts` 的計數規則）

計數規則：**主要決策**＝使用者必須自己選的事（同時算一次點擊）；**安全步驟**＝不可省略的確認
（算點擊、**不**算決策——省掉安全步驟不是進步）；**回頭**＝導覽回到造訪過的頁面。

| 任務 | 視窗 | 主要決策 | 點擊 | 回頭 | 安全步驟 |
| --- | --- | --- | --- | --- | --- |
| 第一次使用桌面角色 | 桌面寬度 | 3 | 5 | 0 | 1 |
| 稍後連手機 | 桌面寬度 | 2 | 2 | 1 | 0 |
| 手機與桌面互動 | 桌面寬度 | 0 | 0 | 0 | 0 |
| 暫時離線後恢復 | 桌面寬度 | 0 | 0 | 0 | 0 |
| 等待離線逾時 | 桌面寬度 | 0 | 0 | 0 | 0 |
| 主動移除手機 | 桌面寬度 | 1 | 2 | 0 | 1 |
| 撤銷後重新連線 | 桌面寬度 | 2 | 2 | 1 | 0 |
| 更換角色 | 桌面寬度 | 1 | 2 | 0 | 0 |
| 調整陪伴程度 | 桌面寬度 | 0 | 0 | 0 | 0 |
| 設定安靜時段 | 桌面寬度 | 2 | 3 | 0 | 0 |
| 取消進行中的工作 | 桌面寬度 | 5 | 5 | 0 | 0 |
| 390px：看角色頁並連手機 | 390px | 1 | 1 | 0 | 0 |
| 390px：設定安靜時段 | 390px | 1 | 2 | 0 | 0 |
| 緊急停止 | 桌面寬度 | 2 | 5 | 0 | 2 |

目標「一般任務 3–5 個主要決策」以**上限**解讀：每一列都 ≤ 5，spec 內以
`withinDecisionTarget()` 斷言（超過就紅）。決策數 0 的三列是誠實的事實而不是漏測：

- 「手機與桌面互動」「暫時離線後恢復」「等待離線逾時」的動作發生在手機端，桌面端**不需要**
  任何決策就會自己更新（SSE 推送）；量測的是「桌面端還要人做幾件事」。
- 「調整陪伴程度」在瀏覽器模式**做不到**（Tauri-only），0 代表「這裡連按都沒得按」，
  不代表「一步就完成」。

## 3. 390px 與可及性結果（本輪實跑）

| 檢查 | 結果 |
| --- | --- |
| 390px 橫向溢出（首頁／角色頁／連接頁） | `scrollWidth ≤ innerWidth`，**未發現溢出**；本輪因此**沒有**修改 `styles.css` |
| 390px 角色頁可見控制項（不含收合內容） | **7 個**（測試附件 `390px-character-page-visible-controls`） |
| 同步卡「下一步」鍵盤可達 | 從頁面開頭 Tab 走得到，Enter 真的導到 action id 承諾的落點（配對區／裝置清單） |

| ⌘K 指令面板 | 「緊急停止」永遠在清單裡，且是二段確認：只看清單不會觸發（後端 `emergencyStop` 仍為 `false`） |

## 4. 非開發者測試腳本（**尚未有受測者、尚未執行**）

> 狀態：**未執行**。以下五份腳本是給之後真的找人來測時用的；本輪**沒有**招募任何受測者，
> 也**沒有**任何觀察紀錄。任何人不得把 §2／§3 的自動化數字當成這五份腳本的結果。

共同規則：受測者不看文件、不問旁邊的人；主持人只記錄，不提示。每一步記下
**時間**、**是否卡住**、**卡在哪一句話**。出現任何安全確認（二段確認、套用前確認）時，
記錄受測者是否讀了那句話再按。

### P1「第一次打開」（沒用過這個程式的人）

1. 打開控制中心，照畫面走完首次設定。
2. 走到最後一步時，先講一句「你覺得按下去會發生什麼事」再按。
3. 回到「現在」這一頁，用自己的話說出畫面上三件事分別在講什麼。
4. 找到「角色現在怎麼樣」，說出它現在是什麼狀態。
5. 找到緊急停止在哪裡（**不要按**）。

- 成功判準：不需要提示就走完三步＋套用；能說出「現在」三件事各是什麼；十秒內指出緊急停止。
- 要記錄：在哪一步停下來最久；套用前確認那一段有沒有被讀；有沒有把「首次成功體驗」當成必要步驟。

### P2「把手機接上來」（有 iPhone、沒接過的人）

1. 從角色頁找出「手機還沒接上」這件事。
2. 用畫面上的下一步按鈕，走到可以開始配對的地方。
3. 開始配對，把配對碼唸出來。
4. （主持人操作測試手機完成配對）回到角色頁，說出現在同步狀態是什麼。
5. 說出「已連接」和「已同步」在這個畫面上是不是同一件事。

- 成功判準：不需要自己去翻「連接與權限」的第二層分頁；能講出目前狀態不是「全部完成」。
- 要記錄：有沒有把「iPhone 已連接，能力核對中」誤讀成成功；配對碼有沒有找不到。

### P3「太吵了，讓它安靜」（覺得被打擾的人）

1. 從角色頁找到跟「安靜」有關的地方。
2. 說出畫面上列的幾種「安靜」分別管的是什麼。
3. 設定一段安靜時段（起訖自訂）。
4. 說出設定之後**還會不會**收到安全提示與感測提示。
5. 把安靜時段關掉。

- 成功判準：找得到、設得成、關得掉；能說出「安全提示與感測提示不受安靜設定影響」。
- 要記錄：有沒有以為「安靜」是一個開關；有沒有去找勿擾卻找到主動對話。

### P4「我要它停下來」（安全情境）

1. 交代一件工作（隨便一句話）。
2. 在它進行中把它停掉。
3. 說出畫面現在說這件工作是什麼狀態。
4. 按下緊急停止，走完確認。
5. 說出現在要怎麼把系統恢復。
6. 走完解除流程。

- 成功判準：不需要提示就找得到中斷；能說出「已取消」與「對方說已完成」不一樣；解除時願意走完兩段確認。
- 要記錄：二段確認有沒有被當成多餘；解除流程有沒有人想找「一鍵恢復」。

### P5「手機上的畫面跟電腦不一樣？」（同步語意）

1. （已配對狀態）看角色頁的「同步」卡，說出它現在在講什麼。
2. （主持人讓測試手機離線）說出畫面現在說什麼、你會不會擔心。
3. 等一分鐘，再說一次畫面說什麼。
4. （主持人讓手機接回來）說出現在是不是恢復了。
5. 主動移除這台手機，說出移除之後畫面說什麼。
6. 說出「要再用手機」需要做什麼。

- 成功判準：能分辨「正在重新連線」「暫時離線」「目前只在這台電腦使用」三句話的差別；
  移除之後不會覺得「壞掉了」。
- 要記錄：有沒有人在「正在重新連線」時就去重新配對；移除後的終態句會不會被當成錯誤。
