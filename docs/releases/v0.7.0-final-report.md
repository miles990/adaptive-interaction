## 16. 剩餘限制

完整清單（六類，逐條指得出來源）：`docs/releases/v0.7.0-known-limitations.md`。摘要：

- **真機／真板／受測者**：ESP32 真板零、iPhone 真機零、非開發者受測者 not-run、真 Tauri 走查不在 CI；
  分片路徑在真板上一次都沒有執行過（參考韌體刻意不宣告 `aip.frag/1`）。
- **協定與同步**：SSE 事件流不帶連線世代（規則 0 只擋飛行中的 GET／resume）；typed boundary 三端都不
  要求 `payload.hash`；局部投影（scope）未做，含 members 的 patch 仍整段重送；出站分片中途失敗不重送；
  BLE 沒有 AIP session 端到端測試。
- **裝置生命週期**：rebind 失敗後仍在退避重連；`unresolvedStops` 不跨重啟；動器的 enabled 旗標在 rebind
  後仍回預設（無測試釘住）；純 HTTP 宣告式來源的高風險受器仍 `stop-unknown`。
- **桌面**：陪伴預設恢復只有 vitest＋src-tauri 證據（無真桌面實跑）；清 marker 是第三次寫入；
  `DESKTOP-GUIDE.md` 的 `partial-sync` 列未補。
- **iOS**：`URLSessionSocket` 本身未測；仍未送 AIP `heartbeat`。
- **文件與工具**：`SemanticState` 不在跨語言 schema；沒有測試擋得住選填欄位寫成 `null`；
  `adapter-development.md` §1 把加角色與加 adapter 混成一步。
- **本輪流程本身**：整合全套【整合回填】、對抗審查【對抗審查回填】、perf【perf 回填】、發布【發布回填】。

本輪修掉、不再是限制的：宣告式裝置需重啟才重新綁定、三端 epoch 不一致、Serial 完全收不到 snapshot
（改寫為只對不宣告 `aip.frag/1` 的裝置）、陪伴預設兩段寫入非原子、Tauri-only 正向路徑未在真視窗走查
（`docs/releases/v0.6.x-final-report.md` §11 已就地標註，原文保留）。
