## 4. 受保護行為（重構後必須仍成立）

以恢復矩陣（`docs/releases/v0.6.0-recovery-matrix.md`）每一列的 conclusion 為準；本節只列跨列的硬約束：

1. 上表每個套件的通過數不得下降；新增測試只能加。
2. 一般模式主入口維持五個；`?window=` deep link 與既有路由不變。
3. 小樞 rig／sprite／text 三個 adapter 對 20 個 CPP intent 的協商結果不變（`intent_capabilities_golden`）。
4. iPhone 線協定 v1 的訊息（pair-request／pair-response／auth／status／observation／ack／err／ble.*；act／stop-all／ble.*）
   對舊 App 保持相容：舊 App 遇到未知 `type` 只記錄不執行（`ServerMessage.unknown`）。
5. 配對指紋、每機 token、revoke 即斷線、estop 傳播 stop-all、感測不靜默——全部維持。
6. `claimed-completed ≠ verified`；綠勾只在 verified；emergency 文案固定。
