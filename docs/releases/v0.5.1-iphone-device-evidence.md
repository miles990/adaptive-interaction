# v0.5.1 iPhone 真機證據

## 結論：blocked（App 從未裝上手機，冷啟動測試 0 次執行）

2026-09-04 嘗試在真 iPhone 上驗證 v0.5.1 新增的兩個 iOS 行為（commit `5111208`）——
`ConnectionManager.connectOnLaunchIfDesired()`（系統終止後冷啟動自動重連）與
`ReconnectDiagnosis`（桌面位址變更提示）——並順便重跑 status／haptic／character／sensors-stop
四列既有驗收。**結果是 blocked，不是失敗，也不是通過。**

`xcodebuild` 走到簽 `InteractionCompanion.debug.dylib` 這一步就停住：`codesign` 與 macOS
`SecurityAgent` 同時存在，build log 從那一刻起約 **9 分鐘一個位元組都沒有增加**。這正是
`apps/interaction-ios/README.md`「真機」章節列的 **H3** 人工步驟：第一次
`xcodebuild -allowProvisioningUpdates` 會跳出鑰匙圈視窗要求授權私鑰存取。

**AI 不得代按這個對話框**——那等同代替使用者授予私鑰存取同意，違反 repo `CLAUDE.md` 的
「AI 不可授予 consent」。因此本輪在此誠實停止，並按 pid 終止 codesign／xcodebuild 與本輪自己的
daemon（未用 `pkill`，未影響其他程序）。

## 本輪確認的三個對下一次有用的事實

1. **Team ID 要取自簽章憑證的 `OU` 欄位**，不是憑證 CN 括號內那串。用括號內那串會得到
   `error: No Account for Team "…"` 與「找不到 provisioning profile」而 BUILD FAILED。
2. **描述檔有效至 2027-09**（一年效期，不是免費 Personal Team 的 7 天），且本機這台 iPhone 的 UDID
   **已在描述檔的 `ProvisionedDevices` 內**，不需要重新註冊裝置。
3. **`xcodebuild -destination id=<裝置>` 現在解析得到真機**——v0.5.0 記載的「iOS 平台元件未安裝」
   問題在這台機器上已不復現（8.5 GB runtime 已於 2026-09-03 下載）。改用 OU 的 Team ID 後，
   `device-build.sh --no-launch` 通過了全部五道前置閘門並選到正確的簽章組合。

## 需要的人工步驟（一步，之後才能繼續）

1. Mac 螢幕上有一個鑰匙圈授權對話框（可能被其他視窗蓋住），問是否允許 `codesign` 存取
   Apple Development 憑證的私鑰。按 **「總是允許」**——按「允許」只擋這一次，下一輪建置會再問。
2. 之後重跑（可重跑命令）：
   ```bash
   export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
   export IOS_DEVELOPMENT_TEAM=<簽章憑證 OU 欄位的 10 碼，不是 CN 括號內那串>
   apps/interaction-ios/scripts/device-build.sh --no-launch
   ```
3. 建置成功後起 daemon、開配對 session，用
   `devicectl device process launch … --pairing-payload` 配對，接著才跑冷啟動矩陣。

## 待補的列（人工步驟完成後要記錄什麼）

| 列 | 要記錄的事實 |
|---|---|
| 冷啟動自動重連 | 系統終止 App（不是切背景）後，**不帶** `--auto-connect` 啟動，輪詢 `GET /v1/mobile/status` 直到 `connected:true` 或逾時；至少跑兩次 attempt；每次都記實際秒數 |
| 冷啟動後感測不恢復 | 冷啟動連上後手機自報五項感測旗標必須全 `false`、`status.activeSensors` 必須為空——這是不變量，任何一項為 true 都是缺陷 |
| 位址變更提示 | 把桌面換到另一個區網位址後，記錄 App 是否在**連續 4 次連線層失敗或持續 60 秒**後顯示固定文案「連不上桌面：可能是桌面的網路位址已變更。請在桌面重新產生配對碼並重新配對。」，以及「重新配對」捷徑是否可用；同時確認 TLS 指紋不符／撤銷**不會**走這句 |
| observe-motion | 在 App 開啟「動作」感測後實際搖動手機，記錄 `iphone.motion` 觀察筆數與分類（lifted／shaken／placed／rotated）——v0.5.0 起即未涵蓋 |
| status／haptic／character／sensors-stop 四列重跑 | 確認 v0.5.1 的改動沒有讓 v0.5.0 已驗收的列退化；照抄 daemon 原文，`acknowledged` 不得寫成「已觀察」 |
