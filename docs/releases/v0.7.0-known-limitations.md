# v0.7.0（候選）已知限制

> 本文件彙整**第二輪**（分支 `feature/v0.6.x-maintainability`，起點 `f5b8e2f`，28 個 commit）
> 結束時仍然成立的限制。每一條都指得出來源：程式碼檔案、測試名、文件章節，或
> `CHANGELOG.md` `[Unreleased]` 的「本輪（v0.7.0 候選）」段。
>
> **分類用字**：`needs-environment` ＝ 需要本機沒有的硬體／人；`deferred` ＝ 有設計方向但本輪
> 刻意不做；`partial` ＝ 主要缺口已關、剩下的範圍寫在該條；`by-design` ＝ 刻意保留的取捨。
> 真機／真板／受測者的執行次數一律照實寫，模擬器（iOS Simulator、pty `esp32-serial-sim.py`、
> in-process MQTT broker）與 fixture 逐條標明，**不得**被引用成真機／真板證據。

> 審查處置表；審查結束後在此補一節，格式比照 `docs/releases/v0.6.0-known-limitations.md` §2。
>
